# NextXus Research Hub

The free API stack behind the NextXus Federation, documented with links. It explains how work is routed across free providers and which research sources supply verifiable facts and media.

## What is documented

- The free API stack: reasoning and conversation go to DeepSeek; code goes to MiMo; short, fast jobs go to Cerebras or Groq; Mistral is the fallback so there is always an alternative and no single point of failure
- How work is routed
- Research sources: NASA, YouTube Data, Unsplash, Wikipedia
